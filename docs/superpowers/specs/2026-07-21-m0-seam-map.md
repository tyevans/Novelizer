### `novelizer/canon/committer.py`

- `Committer` (committer.py:9-21) — generic-as-is — a single seam class holding an `EventStore`; no fiction import used within the class body.
- `Committer.commit` (committer.py:20-21) — generic-as-is — signature `(agent_name: str, event_type: str, aggregate_id: str, payload: BaseModel)`; appends directly via `EventStore.append`, no `EventType` or fiction payload reference.
- `GatingCommitter` (committer.py:24-46) — generic-as-is (mechanism) / needs-generalization (one literal reference) — the class shape (wraps `EventStore` + a `policy`) is domain-neutral, but its `commit` method (committer.py:35-46) references `EventType.PROPOSAL_CREATED` by literal string when routing a gated call into the proposal queue. The gating/proposal *mechanism* generalizes; the specific constant it imports from the fiction `EventType` registry (`novelizer.canon.events.EventType`) does not move as-is — a generalized substrate needs its own generic "proposal created" event-type constant that this class would reference instead.
