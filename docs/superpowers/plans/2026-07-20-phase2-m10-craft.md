# M10 "Craft" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Craft knowledge becomes pull-able capability: five SKILL.md packs served read-only at `/skills/`, a writable `/workspace/` scratch for think-in-files deliberation, per-agent skills assignment (chat personas included), plus the accumulated M10 queue (checker promise-mining, search kinds, orphaned-pivot finding, multi-character arc oracle) — Phase 2's M10 (docs/MILESTONES.md).

**Architecture:** deepagents 0.6.12's `SkillsMiddleware` (attached via `create_deep_agent(skills=[...])`) reads SKILL.md sources through the agent's OWN backend with built-in progressive disclosure (name+description in the system prompt; body + references pulled via `read_file`). So skills ship as package data (`novelizer/skills_packs/`) served by a read-only filesystem route at `/skills/` on the existing CompositeBackend; `skills=` receives `/skills/<pack>` source paths. `/workspace/` mounts a `StateBackend` (run-scoped scratch, writable — the ONLY writable route; canon and outline stay read-only). Mining and search kinds extend the established M4/M7 patterns.

**Tech Stack:** Python 3.13, deepagents 0.6.12 (SkillsMiddleware, FilesystemBackend, StateBackend, CompositeBackend), pydantic v2, Hypothesis, pytest asyncio_mode=auto.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-19-authoring-skills-blueprint-design.md` §"Skills packs", §"Backend composition" (/workspace/ semantics). M10 acceptance (docs/MILESTONES.md): the Engine Room shows a skill activate and a beat-table reference pulled mid-plan (satisfied by existing tool telemetry showing `read_file` under `/skills/`); a chat persona answers a pacing question grounded in the ledger and framework.
- SKILL.md format (deepagents contract): YAML frontmatter `name` (lowercase-hyphens, must match parent dir) + `description` (what + when to activate); body < ~2k words; `references/` files pulled on demand. Verify loading against the INSTALLED SkillsMiddleware (`deepagents/middleware/skills.py`) — its `sources` are paths on the agent's backend.
- Craft content comes from the research notes (`docs/superpowers/specs/assets/2026-07-19-authoring-skills-research.md`) — beat tables, obligatory scenes, arc invariants, outcome taxonomy. Content must be data-dense reference material, not vibes.
- `/workspace/` is never canon, never projected; canon/outline writes keep refusing with the intent-path message. Skills route refuses writes with the same canonical message.
- Skills attach ONLY on tooled builder paths (they require the backend); bare paths unchanged byte-identical.
- Established invariants: reset-tuple completeness for any new table (none expected); mined events carry `source="mined"`; notes empty-when-quiet.
- **Run all tests in this worktree, NEVER the main checkout.** Synchronous only — implementers/reviewers NEVER use background runs or monitors.
