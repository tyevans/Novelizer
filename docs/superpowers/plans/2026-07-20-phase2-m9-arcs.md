# M9 "Arcs" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Character interiority becomes authored structure: a character-arc aggregate (ghost/lie/truth/want/need, five arc types) declared and advanced by the CharacterKeeper, pivots pinned to blueprint beats, checked by an `arc_alignment` Brain faculty, visualized on a new Arcs Brain tab — Phase 2's M9 (docs/MILESTONES.md).

**Architecture:** The arc aggregate mirrors delivered patterns exactly: uuid-minted arc ids (like briefs), one ACTIVE arc per character with per-character supersession on re-declaration (mirroring blueprint supersession scoped to `character_id`), absorbing `resolved` terminal. The planned arc complements — never replaces — `Character.arc_status` (the Keeper's freeform observed snapshot): `arc_alignment` compares plan against observation. Arc events are never-gated agent authoring (like threads/promises). The Arcs tab is BrainPanel tab 6 with a sixth `alarm_strip` segment. Also lands the M8-named deferral: drift-aware Plotter readiness.

**Tech Stack:** Python 3.13, pydantic v2, Hypothesis, pytest asyncio_mode=auto, Textual pure-model widgets.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-19-authoring-skills-blueprint-design.md` §"Character arcs", §Brain faculties, §TUI. Roadmap: docs/MILESTONES.md M9 row (acceptance: a fall arc resolving `truth_embraced` raises a contradiction alarm; a stagnant arc surfaces and the Plotter routes its character into the next brief).
- Event-sourcing rules as established: minted-once ids, absorbing terminals, projector no-ops for unknown/terminal citations, every new table in `_reset_state_locked`'s tuple.
- Arc types: `positive | flat | disillusionment | fall | corruption`. Resolution outcomes: `truth_embraced | lie_embraced | truth_tragic | world_changed`. Consistency table (contradiction = resolved outcome NOT in the type's row): positive→{truth_embraced}, flat→{world_changed, truth_embraced}, disillusionment→{truth_tragic}, fall→{lie_embraced}, corruption→{lie_embraced}. A contradiction is an ALARM for the Director to adjudicate, never an error — the story may have earned it.
- `Character.arc_status` is untouched (observed state, Keeper-owned); the arc aggregate is the plan.
- All four arc event types → `_NEVER_GATED` (agent authoring; only blueprint adoption is `_ALWAYS_GATED`).
- Brain faculties pure; notes empty-when-quiet; TUI reuses faculties.

### Task 1: Arc event types + payloads

**Files:** Modify `novelizer/canon/events.py`; test `tests/canon/test_events.py` (append).

**Interfaces:** Constants `ARC_DECLARED = "arc.declared"`, `ARC_PIVOT_PLANNED = "arc.pivot_planned"`, `ARC_ADVANCED = "arc.advanced"`, `ARC_RESOLVED = "arc.resolved"`. Payloads (docstring style per the file's locked-decision convention):

```python
class ArcDeclared(BaseModel):
    """Payload for arc.declared — mints a character's planned arc.

    `arc_id` is minted (uuid) by the committing helper. One arc is ACTIVE per
    character at a time: declaring supersedes the character's prior active arc
    in projection (Locked decision #1, mirroring blueprint supersession scoped
    to character_id). The declared plan complements Character.arc_status (the
    Keeper's observed snapshot) — it never replaces it."""
    arc_id: str
    character_id: str
    arc_type: str            # positive|flat|disillusionment|fall|corruption
    ghost: str = ""
    lie: str = ""
    truth: str = ""
    want: str = ""
    need: str = ""
    note: str = ""


class ArcPivotPlanned(BaseModel):
    """Payload for arc.pivot_planned — pins an internal pivot to a blueprint
    beat, cited by arc_id + beat_id. Re-emission for the same (arc, beat)
    supersedes. Unknown/resolved arcs and unknown beats are projection no-ops."""
    arc_id: str
    beat_id: str
    description: str = ""


class ArcAdvanced(BaseModel):
    """Payload for arc.advanced — evidence the arc moved in a chapter, cited
    by arc_id. No-op on resolved arcs."""
    arc_id: str
    chapter_id: str = ""
    note: str = ""


class ArcResolved(BaseModel):
    """Payload for arc.resolved — terminal and absorbing. `outcome` is one of
    truth_embraced|lie_embraced|truth_tragic|world_changed; an outcome
    inconsistent with the declared arc_type is an arc_alignment ALARM for the
    Director, never a projection error (Locked decision #2)."""
    arc_id: str
    chapter_id: str = ""
    outcome: str = ""
    note: str = ""
```
